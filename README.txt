منصة الدكتورة أمنية أبو السعود - نسخة تسجيل الدخول ولوحة المطور

الرفع على GitHub Pages:
1) سمّي الملف index.html (هو بالفعل بهذا الاسم).
2) ارفع index.html إلى مستودع GitHub الذي يشغّل الموقع.
3) انتظر تحديث GitHub Pages ثم افتح الموقع.

وظائف النسخة:
- زر "تسجيل الدخول" للطلاب.
- زر "المطور" أعلى الصفحة.
- لوحة المطور محمية بكلمة المرور التي حددتها.
- إضافة اسم الطالب + كود الطالب.
- حذف الطلاب.
- تسجيل دخول الطالب بالاسم والكود.

مهم:
هذه النسخة تستخدم LocalStorage لأنها صفحة GitHub Pages ثابتة؛ لذلك قائمة الطلاب تُحفظ على نفس المتصفح والجهاز الذي أضافها.
إذا أردت أن تضيف الطالب من جهازك ثم يستطيع الطالب الدخول من هاتفه هو، نحتاج في الخطوة التالية ربط الموقع بقاعدة بيانات/خدمة مصادقة.
